# Fonts

The UI theme (`Assets/Scripts/UI/Theme.cs`, `FontProvider`) resolves fonts in this order:

1. `Resources/Fonts/Inter-Regular` / `Inter-SemiBold` / `Inter-Bold` if present (drop the OFL TTFs here).
2. OS runtime fonts: Roboto → Inter → HelveticaNeue → Arial (`Font.CreateDynamicFontFromOSFont`).
3. Unity built-in `LegacyRuntime.ttf`.

So the game renders correctly out of the box and can be upgraded to the Inter family by simply
copying the three TTFs into this folder (and their `.ttf.meta` will be generated by Unity).
